# [AL.M.007] Оценивание эффектов обучения

## Definition and purpose

Метод определяет допустимые выводы об участии, освоении, поведении и результатах контекста и собирает соразмерные этим выводам данные.

Для освоения метод валидирует не задание «вообще», а конкретную интерпретацию данных и решение. Он связывает модель способности, доказательство и свойства задания, учитывает выборку задач, режим поддержки и последствия ошибочного решения.

Для научения из ошибки или инцидента метод разделяет цепочку `событие → вывод → изменение → внедрение → соблюдение → результат → устойчивость → перенос`. Каждое звено получает собственный показатель; данные раннего звена не подменяют данные последующего.

## Forces

| Force | Tension |
|---|---|
| Полнота данных ↔ стоимость измерения | Измерение должно быть достаточным, но практически выполнимым |
| Причинный вывод ↔ сложность контекста | Изменения имеют альтернативные объяснения |
| Стандартизация ↔ аутентичность | Сопоставимость не должна уничтожать связь с реальной работой |
| Узкая проба ↔ широкий вывод | Одна задача не должна представлять неоднородную способность без основания |
| Прозрачность шкалы ↔ правильность критерия | Явный критерий может последовательно измерять несущественное действие |
| ИИ ↔ валидность решения | Автоматизация разработки или оценки требует проверки используемых признаков и человеческого пересмотра |

## Key distinctions and bias

- AL.D.006: обратная связь ≠ оценка.
- AL.D.007: удовлетворённость ≠ освоение ≠ перенос.
- групповая способность ≠ индивидуальная предметная способность;
- выполнение в симуляции ≠ выполнение в реальной среде без отдельного основания;
- совпадение машинной и человеческой оценки ≠ совпадение признаков и логики решения;
- число сообщений зависит от реальной частоты событий, экспозиции, обнаружимости, классификации и готовности сообщать;
- административное закрытие изменения ≠ принятие ≠ охват ≠ соответствие замыслу ≠ операционный эффект;
- отсутствие повторения редкого события без подходящего знаменателя и временного ряда не доказывает результат;
- опережающий показатель считается проверяемой контекстной гипотезой до подтверждения связи с последующим исходом;
- **Bias:** подтверждение успеха — собираются только удобные данные, поддерживающие программу.

## Failure modes

AL.FM.005, AL.FM.006, AL.FM.010.

## SoTA

`current` как доказательный подход. Конкретные причинные выводы имеют статус не выше качества дизайна и данных. Измерительная цепочка, раздельная оценка внедрения и результата, неоднозначность числа сообщений и границы опережающих показателей приняты по AL.SOTA.016; валидность интерпретации, выборка задач, режим поддержки, групповое доказательство и ИИ-оценивание — по AL.SOTA.019. Отсутствие повторения как доказательство имеет статус `bounded`. Пересмотреть, если используемые индикаторы не предсказывают целевое действие.
